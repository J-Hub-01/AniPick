# AniPick
> Discover your next anime effortlessly — browse trending shows, filter by genre, and explore detailed synopses.

---

## Problem
> With a vast number of anime available, both new and experienced viewers often struggle to decide what to watch next.

---

## Solution
> AniPick filters out the trending anime by letting users choose their preferred genre, or recommends the anime that are currently
popular.

---

## Features
- Displays the trending anime list.
- Allows Genre-based search.
- Offers an expandable Synopsis card.

---

## Tech Stack
### Frontend
  - HTML5
  - CSS3
  - JavaScript (ES6)
### API
  - Jikan API (4.0.0)
